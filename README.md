# AutoLoc
Application de gestion de location de voitures

## Présentation du projet
AutoLoc est une application de gestion de location de voitures.

## Acteurs du système

- **Client :** consulte les voitures disponibles et effectue des demandes de réservation.
- **Agent d'agence :** gère les réservations et les opérations de location.
- **Responsable d'agence :** supervise les activités de l'agence.
- **Administrateur :** gère les utilisateurs et les paramètres de l'application.

## Cas d'utilisation

### Client
- Consulter les voitures disponibles
- Effectuer une réservation
- Consulter ses réservations

### Agent d'agence
- Gérer les réservations
- Gérer les opérations de location
- Gérer les informations des voitures

### Responsable d'agence
- Superviser les activités de l'agence
- Consulter les données de gestion

### Administrateur
- Gérer les utilisateurs
- Gérer les paramètres de l'application

## Technologies
